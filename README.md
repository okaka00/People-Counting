# People-Counting

This project is an autonomous people counting system developed using a robotic car equipped with a Jetson Nano. The system uses the YOLOv5 object detection model to identify and count people in real time while the robot moves through an environment. The robot is capable of navigating autonomously, avoiding obstacles, and providing accurate people count data without requiring manual monitoring. A Gradio-based interface was also developed to display detection results and the current people count through image, video, and live webcam inputs.
